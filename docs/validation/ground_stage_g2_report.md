## Coordinate-frame audit

The production satellite-position contract is project ECEF in kilometers, generated by the existing `HypatiaAdapter` from SGP4/WGS72 TEME coordinates using its GMST Z-axis rotation.

```text
frame: project ECEF
frame contract version: hypatia_ecef_gmst_v1
units: kilometers
satellite IDs: integers
timestamps: epoch + timestep × step seconds, UTC
```

Ground stations are converted from WGS84 geodetic coordinates to fixed ECEF coordinates. No additional Earth rotation is applied in G2.

The model does not claim high-precision ITRF, Earth-orientation, polar-motion, UT1, or sub-meter geodetic fidelity.

## WGS84 model

```text
semi-major axis: 6378.137 km
flattening: 1 / 298.257223563
model version: wgs84_geodetic_ecef_v1
```

Validated cases include equator/prime meridian, equator/90° east, north pole, nonzero altitude, negative valid altitude, southern latitude, and western longitude.

Ground altitude is interpreted as WGS84 ellipsoidal height. No orthometric/geoid claim is made.

## Timestamp contract

Canonical timestamps always use:

```text
YYYY-MM-DDTHH:MM:SS.ffffffZ
```

Tests reject naive timestamps, nonzero UTC offsets, and alternate equivalent strings. Operational timestamps derive only from rollout epoch and timestep interval.

